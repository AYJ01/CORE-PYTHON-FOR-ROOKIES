# Networking Practical Questions

1. Explain the difference between TCP and UDP.
2. Create a TCP client socket.
3. Create a TCP server socket.
4. Explain IP addresses and port numbers.
5. Describe the role of DNS.
6. Send and receive bytes over a socket.
7. Use `socket.create_connection()`.
8. Explain host names and IPv4 versus IPv6.
9. Make an HTTP `GET` request.
10. Make an HTTP `POST` request.
11. Read an HTTP status code and headers.
12. Decode a JSON HTTP response.
13. Add a request timeout.
14. Explain the difference between HTTP and HTTPS.
15. Describe common HTTP status classes.
16. Explain REST API resources.
17. Send JSON in a request body.
18. Read API data from environment variables.
19. Explain network and protocol errors.
20. Protect API credentials.

## Mini-project

Build a command-line API client that accepts a URL, sends a request with a timeout, validates the status code, decodes JSON, and prints selected fields or a clear error message.
