# Advanced Functions Practical Questions

1. Calculate a factorial recursively.
2. Calculate the sum of numbers recursively.
3. Calculate a Fibonacci number recursively.
4. Write a recursive countdown.
5. Explain the base case and recursive case.
6. Create a closure that adds a fixed value.
7. Create a closure that maintains a counter.
8. Explain how closures retain state.
9. Create a logging decorator.
10. Create a timing decorator.
11. Use `functools.wraps` in a decorator.
12. Decorate a function that accepts arguments.
13. Write a higher-order function that applies an operation.
14. Return a validator function from a function.
15. Use `map()` with a function.
16. Use `filter()` with a function.
17. Use `sorted()` with a key function.
18. Annotate parameters and return values.
19. Annotate a list parameter.
20. Explain that annotations are not runtime enforcement.

## Mini-project

Create a reusable decorator that validates function arguments against expected minimum and maximum values, and demonstrate it with an area or pricing function.
