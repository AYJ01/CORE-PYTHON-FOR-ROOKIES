# Functions Practical Questions

1. Define a function that prints a greeting.
2. Pass a name to a greeting function.
3. Give a function parameter a default value.
4. Add two numbers with a function.
5. Return the larger of two numbers.
6. Return both quotient and remainder from a division.
7. Define a function with `*args`.
8. Define a function with `**kwargs`.
9. Define keyword-only parameters.
10. Calculate area with a function.
11. Convert Celsius to Fahrenheit.
12. Test whether a number is prime.
13. Print a list using a function.
14. Return the average of numbers.
15. Demonstrate a local variable.
16. Demonstrate a global variable.
17. Modify a counter using `global`.
18. Modify an enclosing variable using `nonlocal`.
19. Create a lambda that squares a number.
20. Sort records using a lambda key.

## Mini-project

Create a command-line calculator using separate functions for addition, subtraction, multiplication, division, and input validation. Let the user select an operation repeatedly until they choose to exit.
