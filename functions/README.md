## Example

```python
def greet(name):
    return f"Hello, {name}!"

message = greet("Asha")
print(message)
```

## Function concepts

- Define reusable behavior with `def`.
- Pass input values through parameters.
- Return results with `return`.
- Reuse functions by calling their names.
- Organize related code into small, focused functions.
