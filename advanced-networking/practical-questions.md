7. Use `asyncio.open_connection()`.
8. Handle partial socket reads.
9. Frame messages with a length prefix.
10. Design an application protocol.
11. Detect oversized frames.
12. Validate untrusted network input.
13. Implement connection timeouts.
14. Implement retry backoff.
15. Define an idempotency key.
16. Explain keep-alive connections.
17. Design graceful shutdown.
18. Explain cancellation in async networking.
19. Protect secrets and private keys.
20. Describe backpressure.

## Mini-project

Build a small JSON-lines or length-prefixed TCP service with TLS, bounded frame sizes, request timeouts, graceful shutdown, and a concurrent async client.
