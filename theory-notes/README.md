# Python Theory Notes: a friendly map to Python mastery

Welcome! This guide explains what the folders in this repository teach, how they fit together, and what to do when you get stuck. It is written for curious beginners—including children—but it is useful at any age. You do not need to understand everything at once.

> **The big idea:** learning Python is like learning to build with LEGO. First learn the pieces, then how they fit together, and finally build your own creations. Read a little, type the examples, change them, and see what happens.

## Start here

1. Read [Getting Started](../getting-started/README.md). Install Python and run your first program.
2. Follow the [learning path](learning-path.md) in order. It starts with simple ideas and adds new ones gradually.
3. Use the [directory guide](directory-guide.md) when you wonder what a folder is for.
4. Use the [glossary](glossary.md) when a programming word feels unfamiliar.
5. Choose a tiny project from [practice and projects](practice-and-projects.md) to put your skills together.

## How to learn from each lesson

For each page, try this small routine:

1. **Read one idea.** You do not have to read a whole folder in one sitting.
2. **Say what you think the code will do.** A prediction is a useful question, not a test of whether you are clever.
3. **Type the example yourself.** Save it in a `.py` file and run it using the instructions in `getting-started/`.
4. **Change one small thing.** Change a word, number, or name. Predict again and run it.
5. **Read any error message slowly.** It is a clue from Python. Find the line number, check spelling and punctuation, and try again.
6. **Try the practice questions without rushing.** If you get stuck, go back to the example and make a smaller version.

## What the repository teaches

The topic folders move from first steps to larger programs. Foundations include `getting-started`, `variables`, `operators`, `conditional-statements`, `strings`, `collections`, and `functions`. Program-building topics include `iterators`, `modules-and-packages`, `exception-handling`, `file-handling`, `testing`, `virtual-environments`, and `databases`. Later topics include object-oriented design, networking, concurrency, regular expressions, and advanced versions of several subjects. The pages are notes and exercises; mastery comes from writing and improving your own programs too.

## Friendly reminders

- It is normal to forget a detail. Programmers look things up all the time.
- Computers follow instructions exactly. Tiny punctuation marks can matter.
- Make a copy before experimenting with important files.
- Never share passwords, API keys, home addresses, or other private information in code or online.
- Ask a trusted adult for help installing software or using the internet if you are a child.
- “Python mastery” is a journey, not a finish line. You can always learn another useful thing.
