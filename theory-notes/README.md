## How to use theory and practice together

1. Read one focused concept.
2. Predict the result of its example.
3. Type and run the example.
4. Change one variable or function at a time.
5. Complete the topic exercises.
6. Explain the concept in your own words.
7. Combine it with a previous topic in a small project.

## Mental model

Python programs transform input into output:

```text
input → variables and collections → operations and decisions
     → functions and objects → files, databases, or network services
     → output or persistent state
```

Good programs make that transformation clear, validate assumptions, handle failures, and include tests.
