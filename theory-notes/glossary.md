# Glossary: Python words in everyday language

- **Argument:** the actual information you give a function when you use it. If `greet("Sam")` runs, `"Sam"` is an argument.
- **Boolean:** a value that is either `True` or `False`, like a yes/no answer.
- **Bug:** a mistake that makes a program do the wrong thing or stop.
- **Class:** a plan for creating objects, like a pattern for making several similar game characters.
- **Code:** instructions written in a programming language.
- **Collection:** one object that holds several values, such as a list or dictionary.
- **Comment:** a note for people reading code; Python ignores a line beginning with `#` in ordinary code.
- **Condition:** a question that can be true or false, such as `score >= 10`.
- **Dictionary:** a collection that connects keys to values, like a label on a box: `{"color": "blue"}`.
- **Error / exception:** information Python gives when it cannot complete an instruction as written. The message often points to where to look.
- **Expression:** code that produces a value, such as `2 + 3`.
- **File:** information saved with a name on a computer.
- **Float:** a number that can have a decimal part, such as `2.5`.
- **Function:** a named set of steps you can use again. A function can receive inputs and return an answer.
- **Integer:** a whole number, such as `-2`, `0`, or `12`.
- **Iteration:** doing something once for each item, or repeating steps.
- **Key:** the label used to look up a value in a dictionary.
- **List:** an ordered, changeable collection, written with square brackets, such as `["red", "blue"]`.
- **Loop:** code that repeats instructions.
- **Method:** a function that belongs to an object, such as `"hello".upper()`.
- **Module:** a Python file that can provide code for another file to use.
- **Object:** a value Python can work with; objects can have data and actions.
- **Parameter:** a named input in a function definition. In `def greet(name):`, `name` is a parameter.
- **Program:** instructions that work together to accomplish a task.
- **Return value:** the answer a function sends back with `return`.
- **Set:** a collection that keeps unique values; it does not promise a useful order for choosing an item.
- **String:** text inside quotes, such as `"hello"`.
- **Syntax:** the spelling and punctuation rules of Python, like grammar rules for instructions.
- **Test:** code that checks whether another part of a program behaves as expected.
- **Tuple:** an ordered collection, often used for a group of values that should stay together.
- **Type:** the kind of value something is, such as an integer, string, or Boolean.
- **Variable:** a name that refers to a value, like `lives = 3`.
- **`print()`:** a built-in function that displays information.
- **`input()`:** a built-in function that asks the person running a program to type something; the answer comes back as text.
- **`import`:** a Python instruction that lets a file use code from a module or package.

If a word is not here, search the topic folder named in the [directory guide](directory-guide.md), then add the word to your own notes.
