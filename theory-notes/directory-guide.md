# Directory Guide: what each topic folder is for

This is a map of the topic directories currently present in the repository. Open a directory's `README.md` first; it is the table of contents for that topic. The descriptions below explain the purpose and the lesson pages in plain language.

## First steps and everyday Python

- [`getting-started/`](../getting-started/README.md) — `installing-python.md` gets Python ready; `running-python.md` explains starting a program; `first-program.md` makes a first tiny program; `interactive-mode.md` lets you try instructions one by one; `comments.md` explains notes for human readers; `practical-questions.md` is practice.
- [`variables/`](../variables/README.md) — `integer.md` covers whole numbers; `float.md` covers decimal-style numbers; `string.md` covers text values; `boolean.md` covers `True` and `False`; `type-conversion.md` changes a value from one type to another; `practical-questions.md` gives exercises. The folder README also introduces naming, assignment, dynamic typing, and swapping.
- [`operators/`](../operators/README.md) — `arithmetic.md` calculates; `assignment.md` stores or updates; `comparison.md` asks questions such as “is this bigger?”; `logical.md` combines true/false tests; `identity.md` checks whether two names point to the same object; `membership.md` checks whether something is inside a group; `precedence.md` explains which operation happens first; `bitwise.md` works with the binary bits of integers; `practical-questions.md` mixes the ideas.
- [`conditional-statements/`](../conditional-statements/README.md) — `if.md` makes one decision; `if-else.md` chooses one of two paths; `elif.md` checks several choices; `nested.md` puts a choice inside another choice; `reference.md` is a quick reference; `practical-questions.md` is practice.
- [`strings/`](../strings/README.md) — `creating-strings.md` makes text; `string-indexing.md` reads one character by position; `string-slicing.md` takes a part; `string-methods.md` uses built-in text actions; `formatting-strings.md` puts values into messages; `practical-questions.md` checks understanding.
- [`collections/`](../collections/README.md) — groups of values. `list/` teaches ordered, changeable lists; `tuple/` teaches ordered, usually unchanging groups; `set/` teaches unique items and set operations; `dictionary/` teaches key/value pairs. Each subfolder has pages for creating, accessing or changing, operations, and exercises; lists, sets, and dictionaries also have comprehension lessons.
- [`functions/`](../functions/README.md) — `defining.md` makes a named recipe; `parameters.md` passes information in; `return-values.md` sends an answer back; `scope.md` explains where names can be used; `lambda.md` introduces short anonymous functions; `practical-questions.md` gives practice.
- [`iterators/`](../iterators/README.md) — `for-loops.md` repeats for each item; `while-loops.md` repeats while a condition holds; `loop-control.md` changes or ends a loop; `using.md` uses iterators; `protocol.md` explains the iterator rules; `custom.md` builds an iterator; `generators.md` creates values on demand with `yield`; `patterns.md` shows common uses; `practical-questions.md` gives exercises.

## Building useful programs

- [`modules-and-packages/`](../modules-and-packages/README.md) — `creating-modules.md` splits code into files; `import-styles.md` imports names; `python-packages.md` groups modules; `module-search-path.md` explains where Python looks; `virtual-environments.md` points to isolated project tools; `practical-questions.md` is practice.
- [`exception-handling/`](../exception-handling/README.md) — `try-and-except.md` responds to expected errors; `built-in-exceptions.md` identifies common error types; `raising-exceptions.md` reports invalid situations; `custom-exceptions.md` creates meaningful error types; `else-and-finally.md` handles success and cleanup; `practical-questions.md` gives exercises.
- [`file-handling/`](../file-handling/README.md) — `opening-and-closing.md` opens files safely; `text-files.md` reads and writes words; `binary-files.md` handles bytes; `working-with-paths.md` locates files; `csv-and-json.md` works with common data formats; `practical-questions.md` is practice.
- [`testing/`](../testing/README.md) — `assertions.md` checks expected results; `unittest.md` uses Python's built-in test framework; `pytest.md` introduces pytest; `test-discovery.md` helps a test runner find tests; `fixtures.md` prepares reusable test data; `mocking.md` replaces outside dependencies during a test; `practical-questions.md` is practice.
- [`virtual-environments/`](../virtual-environments/README.md) — `why.md` explains isolation; `creating.md` makes an environment; `activating.md` turns it on; `installing-packages.md` installs project tools; `requirements.md` records needed packages; `practical-questions.md` gives exercises.
- [`databases/`](../databases/README.md) — `sqlite-basics.md` introduces SQLite; `creating-tables.md` makes a structure for information; `crud-operations.md` creates, reads, updates, and deletes records; `parameterized-queries.md` safely supplies values to SQL; `transactions.md` groups changes so they succeed or fail together; `relationships.md` connects tables; `practical-questions.md` is practice.

## Objects, patterns, and deeper Python

- [`object-oriented-programming/`](../object-oriented-programming/README.md) — `classes-and-objects.md` introduces blueprints and their instances; `attributes-and-methods.md` adds data and actions; `encapsulation.md` organizes access; `inheritance.md` shares behavior; `polymorphism.md` lets different objects answer the same kind of request; `special-methods.md` connects objects to Python operations; `practical-questions.md` is practice.
- [`advanced-object-oriented-programming/`](../advanced-object-oriented-programming/README.md) — `composition.md` builds objects from other objects; `abstract-base-classes.md` describes shared rules; `data-classes.md` reduces repetitive data-container code; `context-managers.md` manages setup and cleanup; `descriptors.md` customizes attribute access; `metaclasses.md` customizes class creation; `practical-questions.md` is practice. The last two are advanced; they are not required for every project.
- [`advanced-functions/`](../advanced-functions/README.md) — `recursion.md` solves a problem with smaller versions of itself; `closures.md` remembers information from an outer function; `decorators.md` wraps a function to add behavior; `higher-order.md` passes or returns functions; `annotations.md` adds hints about values and types; `practical-questions.md` is practice.
- [`regular-expressions/`](../regular-expressions/README.md) — `basic-patterns.md` matches text shapes; `groups-and-capturing.md` saves parts of a match; `search-and-replace.md` finds or changes text; `flags-and-compilation.md` adjusts or prepares a pattern; `lookarounds.md` checks nearby text without including it in the match; `practical-questions.md` is practice. For simple text changes, ordinary string methods may be easier.

## Internet, speed, and reliability

- [`networking/`](../networking/README.md) — `sockets.md` introduces low-level connections; `http.md` explains web requests and responses; `apis.md` shows a program using a web service; `practical-questions.md` reinforces the ideas.
- [`advanced-networking/`](../advanced-networking/README.md) — `tls.md` explains encrypted, authenticated connections; `async-networking.md` shares an event loop across connections; `protocol-design.md` covers safe message formats and boundaries; `practical-questions.md` is practice.
- [`concurrency/`](../concurrency/README.md) — `threads.md` runs overlapping tasks in threads; `processes.md` uses separate processes; `asyncio.md` coordinates cooperative tasks; `synchronization.md` helps tasks share resources safely; `practical-questions.md` is practice. Learn the basics before using concurrency: it can make programs harder to reason about.
- [`advanced-file-handling/`](../advanced-file-handling/README.md) — `file-modes-and-encoding.md` covers how files are opened and text is represented; `large-files.md` handles data in smaller pieces; `temporary-files.md` makes short-lived files; `archives.md` groups files; `compression.md` reduces file size; `file-locking.md` coordinates access; `practical-questions.md` is practice.
- [`advanced-testing/`](../advanced-testing/README.md) — `parametrization.md` runs one test with many examples; `async-testing.md` tests asynchronous code; `coverage.md` measures which code tests visit; `test-doubles.md` uses substitutes for dependencies; `integration-testing.md` checks parts working together; `property-based-testing.md` tries many generated examples; `practical-questions.md` is practice.
- [`advanced-modules-and-packages/`](../advanced-modules-and-packages/README.md) — `package-initialization.md` explains package startup; `namespace-packages.md` covers a package pattern; `dynamic-imports.md` loads modules by name at runtime; `module-internals.md` looks behind imports; `distribution-and-publishing.md` shares packages; `practical-questions.md` is practice.

## Important navigation note

The root README is a helpful overview, but some links in its learning-path table do not match directories in the current repository tree. For example, the actual folders are `conditional-statements/`, `exception-handling/`, `iterators/`, and `modules-and-packages/`; the root table uses some older or alternate names such as `control-flow/`, `errors-and-exceptions/`, `iterators-and-generators/`, and `modules/`. The `data-types/` folder is also linked there but is not present in the current tree; related beginner material is in `variables/`. Use the real links in this guide or browse the repository root if an old link does not open.
