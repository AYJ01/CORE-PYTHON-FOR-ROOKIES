# Getting Started Practical Questions

1. Verify that Python 3 is installed.
2. Display the Python version.
3. Create `hello.py`.
4. Print `Hello, Python!`.
5. Run the script from a terminal.
6. Start interactive mode.
7. Evaluate `2 + 3` interactively.
8. Add a comment to a script.
9. Prompt the user for a name.
10. Print a personalized greeting.
11. Exit interactive mode.
12. Use `python3` if `python` is unavailable.
13. Create a variable in interactive mode.
14. Print a value using `f`-strings.
15. Check whether a command is on `PATH`.
16. Run code containing an intentional syntax error.
17. Identify the line number in the traceback.
18. Fix the syntax error.
19. Create a second Python script.
20. Explain when to use interactive mode versus scripts.
