# Running Python

## Run a script

Save code in a `.py` file, then run:

```bash
python hello.py
```

On systems where `python` is not available, try:

```bash
python3 hello.py
```

## Run code interactively

```bash
python
```

Enter Python expressions directly at the `>>>` prompt.

## Exit interactive mode

```python
exit()
```

Or press `Ctrl+D` on Linux and macOS, or `Ctrl+Z` followed by Enter on Windows.
