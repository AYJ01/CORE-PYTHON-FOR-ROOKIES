# Installing Python

Python 3 is available for Windows, macOS, and Linux.

## Windows

Download Python from the official Python website and run the installer. Enable **Add Python to PATH** during installation.

## macOS

Use the official installer or a package manager such as Homebrew:

```bash
brew install python
```

## Linux

Most distributions provide Python through their package manager.

```bash
python3 --version
```

## Verify the installation

```bash
python --version
python3 --version
```
