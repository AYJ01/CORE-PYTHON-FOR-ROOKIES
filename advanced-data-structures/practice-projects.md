# Practice Projects

## Mini database engine

Combine a B-tree or LSM-style storage structure with:

- Primary-key lookup
- Range queries
- Inserts and deletes
- Disk-backed pages
- Crash consistency

## Compiler symbol table

Use a trie or scoped hash table to store:

- Variable names
- Function names
- Types
- Scope levels
- Resolution metadata

## Network routing engine

Combine a graph and heap to support:

- Shortest paths
- Route updates
- Negative-cycle detection where appropriate
- Connected components

## Range analytics service

Implement a segment tree or Fenwick tree for:

- Range sums
- Range minimums
- Dynamic updates
- Compressed coordinates
- Range frequency counts

## Duplicate detector

Design a pipeline that uses:

- Hash buckets
- Bloom filters
- Exact verification
- Structured on-disk storage

## Testing checklist

For every implementation, test:

- Empty inputs
- One element
- Repeated values
- Randomized inputs
- Duplicates
- Maximum and minimum values
- Large size and deep structures
- Reference-model comparisons
- Timeouts and memory limits
