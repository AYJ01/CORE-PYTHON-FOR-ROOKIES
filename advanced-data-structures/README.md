## Study sequence

1. Understand the invariant maintained by the structure.
2. Trace insert, update, and delete operations manually.
3. Implement the smallest correct version.
4. Test boundary cases and randomized inputs.
5. Analyze time and space complexity.
6. Compare against simpler structures.

## Complexity conventions

- `n`: number of elements
- `h`: tree height
- `log n`: logarithmic search height
- `α(n)`: inverse Ackermann function, nearly constant
- `k`: matched prefix or query range size
