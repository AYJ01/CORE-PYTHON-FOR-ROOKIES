# Variable Practice Questions

Use these questions to practice variable creation, assignment, naming, and conversion. Try to solve every exercise before looking at a solution.

## Beginner exercises

### 1. Profile

Create variables for:

- name
- age
- city
- is_student

Print each variable on a separate line.

### 2. Arithmetic

Create `a = 18` and `b = 4`.

Calculate:

- sum
- difference
- product
- quotient
- remainder
- a raised to b

### 3. Temperature

Store a Celsius temperature and convert it to Fahrenheit:

```text
F = C × 9/5 + 32
```

### 4. String details

Create `language = "Python"` and print:

- its length
- the first character
- the last character
- the text converted to uppercase

### 5. Input

Read a user's name and print:

```text
Nice to meet you, NAME!
```

## Intermediate exercises

### 6. Shopping total

Create variables for:

- item name
- item price
- quantity
- tax rate

Calculate the tax and total.

### 7. Type inspector

Create one variable of each type: `int`, `float`, `str`, `bool`, and `list`. Print both the value and `type()` of each variable.

### 8. Safe conversion

Read a number from the user. If it converts to an integer, print it doubled. Otherwise, print a friendly error message.

### 9. Swapping

Store `left = "red"` and `right = "blue"`, then swap their values. Print both values afterward.

### 10. Data cleanup

Read a quantity as text, remove surrounding whitespace, and convert it to an integer. Print the square of the quantity.

## Challenge exercises

### 11. Unit conversion

Read kilometers as text and convert them to meters and centimeters.

### 12. Time conversion

Convert a number of seconds into hours, minutes, and remaining seconds.

For example, `3665` seconds becomes:

```text
1 hour, 1 minute, 5 seconds
```

### 13. Temperature classification

Read Celsius as a float. Store whether it is:

- below zero
- at or below freezing
- at or above boiling

Print the Boolean values with labels.

### 14. Variable naming review

Identify the valid Python variable names:

```python
student_name
2student
student-name
student_name2
class
for
```

### 15. Mini calculator

Read two floats and an operator (`+`, `-`, `*`, or `/`) from the user. Print the result. Handle division by zero and unsupported operators.

## Checklist

Before moving to the next topic, make sure you can:

- [ ] Create and update variables.
- [ ] Explain integers, floats, strings, and Booleans.
- [ ] Use `type()` and `isinstance()`.
- [ ] Convert values safely.
- [ ] Read numeric input correctly.
- [ ] Choose descriptive variable names.
