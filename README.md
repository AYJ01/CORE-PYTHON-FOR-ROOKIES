## 👋 Welcome!

This repository is a collection of clear Python 3 notes organized into topic folders. Each page focuses on one idea, explains it with examples, and—where applicable—gives you questions to practice what you learned.

> **New to coding?** No problem. Begin at the top of the learning path, take it one topic at a time, and run the examples yourself.

## ✨ What you’ll find in a topic

- **Plain-language explanations** that introduce concepts step by step.
- **Runnable Python 3 examples** to explore and modify.
- **Practical questions and exercises** to help you learn by doing.
- **Small, focused pages** so you can review one concept at a time.

## 🧑‍💻 How to use this repo

1. **Choose a topic** from the learning path above.
2. **Read the pages in order** and type out the examples instead of only copying them.
3. **Predict what a snippet will do** before running it.
4. **Try the practice questions** without looking at a solution first.
5. **Experiment:** change values, make a mistake, read the error, and figure out why.

To run an example, install Python 3, save the code in a `.py` file, then run it from a terminal:

```bash
python your_file.py
```

Depending on your system, the command may be `python3 your_file.py` instead.

## 🧪 A tiny first program

```python
name = input("What is your name? ")
print(f"Hello, {name}! Welcome to Python 🐍")
```

Try it: change the greeting, ask another question, or print the length of the name.

## 🌟 Learning tips

- **Consistency beats cramming:** a little practice often is more useful than one long session.
- **Make predictions:** guess the output, then run the code and compare.
- **Read errors carefully:** tracebacks are clues that help you find the problem.
- **Keep a playground file:** use it to test ideas safely.
- **Build tiny projects:** a quiz, calculator, or guessing game turns concepts into skills.
