## Welcome

This repository is a collection of clear Python 3 notes organized into topic folders. Each page focuses on one idea, explains it with examples, and, where applicable, gives you questions to practice what you learned.

> [!NOTE]
> **New to coding?** Begin at the top of the learning path, take one topic at a time, and run every example yourself.

## What you'll find in a topic

- **Plain-language explanations** that introduce concepts step by step
- **Runnable Python 3 examples** to explore and modify
- **Practical questions and exercises** to learn by doing
- **Small, focused pages** so you can review one concept at a time

## How to use this repo

1. **Choose a topic** from the learning path.
2. **Read the pages in order.** Type out the examples instead of only copying them.
3. **Predict the output** of a snippet before running it.
4. **Attempt the practice questions** before looking at any solution.
5. **Experiment.** Change values, break things, read the error, work out why.

To run an example, install Python 3, save the code in a `.py` file, and run it from a terminal:

```bash
python your_file.py
```

> [!TIP]
> Depending on your system, the command may be `python3 your_file.py`.

## A tiny first program

```python
name = input("What is your name? ")
print(f"Hello, {name}! Welcome to Python.")
```

Try it: change the greeting, ask another question, or print the length of the name.

## Learning tips

<details open>
<summary><b>Practice</b></summary>
<br>

- **Consistency beats cramming.** A little practice often beats one long session.
- **Build tiny projects.** A quiz, calculator, or guessing game turns concepts into skills.

</details>

<details open>
<summary><b>Debugging mindset</b></summary>
<br>

- **Make predictions.** Guess the output, run the code, compare.
- **Read errors carefully.** Tracebacks are clues that point to the problem.
- **Keep a playground file.** Test ideas safely without touching your main work.

</details>
