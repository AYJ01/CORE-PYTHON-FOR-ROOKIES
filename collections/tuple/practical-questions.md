# Tuples Practical Questions

1. Create a tuple containing five programming languages.
2. Create a one-item tuple.
3. Check whether `(42)` is an integer or a tuple.
4. Print the first and last values of a tuple.
5. Slice a tuple to obtain every second element.
6. Reverse a tuple using slicing.
7. Combine two tuples.
8. Repeat a tuple three times.
9. Check whether a value occurs in a tuple.
10. Iterate through every tuple element.
11. Access an element in a nested tuple.
12. Unpack a three-item tuple into variables.
13. Swap two variables using tuple unpacking.
14. Count occurrences of a value.
15. Find the index of a value.
16. Convert a list into a tuple.
17. Convert a tuple into a list.
18. Demonstrate that tuple reassignment raises `TypeError`.
19. Use a tuple as a dictionary key.
20. Return a pair of values from a function as a tuple.

## Mini-project

Create a program that stores three coordinate points as tuples, finds a selected point, prints its `x` and `y` values through unpacking, and reports the number of matching coordinates.
