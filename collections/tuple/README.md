## Example

```python
coordinates = (10, 20)
name, score = ("Asha", 92)

print(coordinates[0])
print(name)
print(score)
```

## Characteristics

- Ordered: element positions are preserved.
- Immutable: tuple elements cannot be reassigned.
- Indexed: indexes begin at `0`.
- Heterogeneous: elements can have different types.
