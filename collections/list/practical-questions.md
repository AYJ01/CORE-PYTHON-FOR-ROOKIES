# Lists Practical Questions

1. Create a list of five colors.
2. Print the first and last values of a list.
3. Replace the third element.
4. Print every second element using slicing.
5. Reverse a list using slicing.
6. Combine two lists.
7. Repeat a list three times.
8. Check for a value using `in`.
9. Iterate through every list element.
10. Access an element in a nested list.
11. Append a value to a list.
12. Insert a value at position `1`.
13. Remove the first matching value.
14. Sort and reverse a numeric list.
15. Count occurrences of a value.
16. Find a value's index.
17. Create squares for numbers `1` through `10`.
18. Filter positive values from a list.
19. Convert all names to uppercase.
20. Flatten a two-level nested list.

## Mini-project

Create a program that:

- stores names and scores in lists;
- adds a new student and score;
- calculates the average;
- prints passing students;
- uses a list comprehension for filtering or transformation.
