# Indexing and Slicing

## Indexing

```python
names = ["Asha", "Ben", "Chen"]

print(names[0])
print(names[-1])
```

## Updating

```python
numbers = [10, 20, 30]
numbers[1] = 25
print(numbers)
```

## Slicing

```python
numbers = [0, 1, 2, 3, 4, 5]

print(numbers[1:4])
print(numbers[:3])
print(numbers[3:])
print(numbers[::2])
print(numbers[::-1])
```

Slice syntax is `start:stop:step`.
