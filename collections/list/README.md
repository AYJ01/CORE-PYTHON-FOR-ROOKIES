## Example

```python
numbers = [10, 20, 30, 40]

print(numbers[0])
print(numbers[-1])
print(numbers[1:3])

numbers.append(50)
print(numbers)
```

## Characteristics

- Ordered: element positions are preserved.
- Mutable: elements can be changed.
- Indexed: indexes begin at `0`.
- Flexible: elements can have different types.
