# Creating Lists

## Literal syntax

```python
numbers = [1, 2, 3]
names = ["Asha", "Ben", "Chen"]
mixed = [10, "Python", True]
```

## Empty and repeated lists

```python
empty = []
repeated = [0] * 5
```

## From another iterable

```python
numbers = list(range(1, 6))
characters = list("Python")
```

## Copying

```python
original = [1, 2, 3]
copy = original.copy()
```
