# Dictionaries Practical Questions

1. Create a dictionary describing a student.
2. Create an empty dictionary.
3. Add a new key and value.
4. Update an existing value.
5. Access a value using `[]`.
6. Access a missing key safely with `get()`.
7. Check whether a key exists.
8. Iterate through keys.
9. Iterate through values.
10. Iterate through key-value pairs.
11. Remove a key with `pop()`.
12. Remove a key with `del`.
13. Clear a dictionary.
14. Create a dictionary from two lists using `zip()`.
15. Merge two dictionaries.
16. Store a nested student record.
17. Build a dictionary using a comprehension.
18. Filter scores below 70.
19. Convert prices into a new dictionary with tax added.
20. Build a program that counts word occurrences.

## Mini-project

Create a simple inventory program that stores item names and quantities, lets the user add or update an item, prints items with low stock, and calculates the total number of items.
