# Sets Practical Questions

1. Create a set of three programming languages.
2. Create an empty set.
3. Convert a list containing duplicates into a set.
4. Add a value to a set.
5. Remove an existing value with `remove()`.
6. Discard a possibly missing value.
7. Test membership in a set.
8. Iterate over a set.
9. Demonstrate that sets have no indexing.
10. Create the union of two sets.
11. Find the intersection of two sets.
12. Find values unique to the first set.
13. Find symmetric differences.
14. Check whether one set is a subset.
15. Check whether two sets are disjoint.
16. Update a set with values from another iterable.
17. Create a set of squared values.
18. Filter a set to retain only even values.
19. Normalize and deduplicate a list of names.
20. Find common tags in two blog posts.

## Mini-project

Create a program that stores subscriber names in two sets, calculates both groups' union and intersection, and prints unique subscribers for the first group and the second group.
