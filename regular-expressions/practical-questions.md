# Regular Expressions Practical Questions

1. Search for a word in a string.
2. Find all digits in a string.
3. Extract all email addresses.
4. Validate a username.
5. Validate a strong password.
6. Match phone numbers.
7. Extract dates in `YYYY-MM-DD` format.
8. Split text using multiple separators.
9. Replace all whitespace with one space.
10. Remove HTML tags from a string.
11. Capture values with named groups.
12. Use a non-capturing group.
13. Compile a reusable pattern.
14. Perform case-insensitive matching.
15. Match text across multiple lines.
16. Use a positive lookahead.
17. Use a negative lookbehind.
18. Extract URLs beginning with `https://`.
19. Find duplicate words in text.
20. Write a log parser that extracts timestamp, level, and message.

## Mini-project

Create a text analyzer that accepts a block of text and reports email addresses, URLs, phone numbers, dates, and duplicate words. Provide both search and replacement operations through a command-line interface.
