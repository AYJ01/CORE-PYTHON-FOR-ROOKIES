# Operators Practical Questions

Use Python to solve these combined operator exercises.

## Arithmetic

1. Create `length = 12` and `width = 8`; calculate area and perimeter.
2. Convert `3.5` hours into minutes.
3. Calculate the remainder of `29 // 6` and `29 % 6`.
4. Use exponentiation to calculate `15 ** 2`.
5. Convert `3665` seconds into hours, minutes, and seconds.

## Assignment

6. Start with `score = 50`; add `10`, subtract `5`, and double it.
7. Swap `left = 100` and `right = 200` without temporary variables.
8. Assign `first`, `second`, and `third` in one statement.
9. Use `+=` to sum a list of numbers.
10. Use `%= 10` to keep a counter in a ten-value cycle.

## Comparison

11. Check whether `age >= 18` and `age <= 65`.
12. Compare `"cat"` and `"dog"` lexicographically.
13. Check whether `45` is outside the range `10` to `40`.
14. Determine whether two strings contain exactly the same text.
15. Check whether a temperature is below `0`.

## Logical

16. Check whether a person is an adult and has a ticket.
17. Check whether a value is a member or staff guest.
18. Return a default name when `name` is empty.
19. Prevent an age from being below `0` or above `120`.
20. Use short-circuit evaluation to avoid division by zero.

## Identity and membership

21. Check whether a variable is `None` using `is`.
22. Create two equal lists and compare identity and equality.
23. Check whether `"z"` is in `"Python"`.
24. Check whether a key is in a dictionary.
25. Check whether a value is in `dictionary.values()`.

## Bitwise

26. Convert `11 & 6` to a binary string.
27. Multiply `9` by `16` using a left shift.
28. Divide `96` by `8` using a right shift.
29. Toggle the lowest bit of `10` using XOR.
30. Print both the number and binary form of `3 | 5`.

## Precedence

31. Evaluate `2 + 3 * 4 ** 2`.
32. Rewrite `a or b and c` with parentheses to communicate intent.
33. Explain the result of `10 + 20 / 5 * 2`.
34. Use parentheses to force `(10 - 3) * 4`.
35. Break down a complex condition into named variables.

## Combined mini-project

Create a Python program that:

- stores a score, number of attempts, and membership status;
- adds bonus points using an assignment operator;
- checks whether the score is at least `70`;
- checks whether the user is a member or has no remaining attempts;
- prints whether they are eligible;
- displays whether a status object is `None` using identity;
- checks whether the score exists in a list of winning scores.
