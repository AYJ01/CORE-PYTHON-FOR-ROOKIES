# Formatting Strings

## f-strings

```python
name = "Asha"
age = 21

print(f"My name is {name} and I am {age}.")
```

## Expressions

```python
value = 12
print(f"Double: {value * 2}")
```

## Formatting numbers

```python
price = 19.5
print(f"Price: ${price:.2f}")
print(f"{123456:,}")
```

## format() method

```python
print("Hello, {}!".format("Python"))
```
