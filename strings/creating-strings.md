# Creating Strings

Use single or double quotes to create a string.

```python
first = 'Hello'
second = "Python"
```

## Multi-line strings

```python
message = """This is
multiple lines."""
```

## Escape sequences

```python
print("Line one\nLine two")
print("Say \"hello\"")
print('It\'s Python')
```

Use raw strings when backslashes should remain unchanged:

```python
path = r"C:\Users\Asha"
```
