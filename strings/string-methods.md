# String Methods

Common methods transform or inspect strings.

```python
text = "  Python Programming  "

print(text.strip())
print(text.lower())
print(text.upper())
print(text.replace("Python", "Java"))
print(text.startswith("  Python"))
print("Programming" in text)
print(text.split())
```

## Joining strings

```python
words = ["Core", "Python", "for", "Rookies"]
print(" ".join(words))
```
