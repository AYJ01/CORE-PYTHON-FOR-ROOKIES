# Strings Practical Questions

1. Create a string in single quotes.
2. Create a string in double quotes.
3. Use a triple-quoted string.
4. Print the first character of `Python`.
5. Print the last character using negative indexing.
6. Slice `Python` to get `Pyt`.
7. Reverse a string.
8. Convert text to lowercase.
9. Convert text to uppercase.
10. Remove whitespace with `strip()`.
11. Replace a word in a string.
12. Split a sentence into words.
13. Join words with hyphens.
14. Check whether text starts with a prefix.
15. Check whether text contains a substring.
16. Format a name and age with an f-string.
17. Format a number to two decimal places.
18. Escape a double quote.
19. Create a raw Windows path string.
20. Attempt to modify a character in a string.

## Mini-project

Build a name formatter that cleans whitespace, capitalizes a person's name, and prints a welcome message with a formatted age or score.
