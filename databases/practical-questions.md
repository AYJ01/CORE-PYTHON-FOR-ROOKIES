# Databases Practical Questions

1. Connect to a SQLite database.
2. Create a users table.
3. Add a primary key.
4. Add `NOT NULL` constraints.
5. Insert a user.
6. Read all users.
7. Read one user by ID.
8. Update a user.
9. Delete a user.
10. Parameterize a search query.
11. Demonstrate why SQL interpolation is unsafe.
12. Start an explicit transaction.
13. Commit a transaction.
14. Roll back a failed transaction.
15. Enable SQLite foreign keys.
16. Create an authors table.
17. Create a books table with a foreign key.
18. Join authors and books.
19. Close database connections reliably.
20. Export a database backup.

## Mini-project

Create a library database containing authors, books, and loans. Implement parameterized CRUD operations, foreign-key relationships, and a transaction that records both a loan and an availability change.
