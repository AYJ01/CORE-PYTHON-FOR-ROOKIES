# Modules and Packages Practical Questions

1. Create a module containing helper functions.
2. Import a module with `import`.
3. Import a function with `from ... import ...`.
4. Import a module using an alias.
5. Avoid wildcard imports.
6. Add a module entry point with `if __name__ == "__main__"`.
7. Create a package directory.
8. Add `__init__.py` to a package.
9. Import a module from a package.
10. Use a relative import.
11. Inspect `sys.path`.
12. Resolve a missing-module import error.
13. Create a virtual environment.
14. Activate the environment.
15. Install a package with `pip`.
16. Generate `requirements.txt`.
17. Add `.venv` to `.gitignore`.
18. Import `json`, `csv`, or `pathlib`.
19. Create a package with multiple subpackages.
20. Reuse code across two small applications.
