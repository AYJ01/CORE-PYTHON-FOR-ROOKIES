## How to study

For every structure, learn:

1. **Definition:** what the structure represents.
2. **Operations:** insert, remove, search, update, and traverse.
3. **Representation:** how data is stored in memory or nodes.
4. **Complexity:** time and space for each common operation.
5. **Use cases:** which problems fit naturally.
6. **Trade-offs:** strengths, weaknesses, and alternatives.
7. **Implementation:** Python code with invariants and validation.

## Complexity notation

- `O(1)` — constant time
- `O(log n)` — logarithmic time
- `O(n)` — linear time
- `O(n log n)` — linearithmic time
- `O(n²)` — quadratic time

Use worst-case complexity by default unless a structure explicitly defines an average or amortized case.
