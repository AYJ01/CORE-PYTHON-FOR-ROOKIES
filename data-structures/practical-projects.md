# Practical Projects

Use these projects to combine data structures with Python fundamentals.

## Beginner

1. **Text Counter:** use a dictionary to count words.
2. **Unique Tasks:** use a set to remove duplicate names.
3. **History Manager:** use a stack for undo operations.
4. **Call Queue:** use `deque` for customer requests.

## Intermediate

1. **Expression Calculator:** tokenize input and evaluate with stacks.
2. **Social Network:** represent friends with an adjacency list and run BFS.
3. **Task Scheduler:** use a heap priority queue.
4. **Spell Checker:** use a trie or set of known words.
5. **Maze Solver:** implement DFS and BFS.

## Advanced

1. **Route Finder:** implement Dijkstra and A* search.
2. **In-Memory Database:** combine hash tables, indexes, and B-trees.
3. **Cache:** implement an LRU cache with a dict and doubly linked list.
4. **Dynamic Range Engine:** use a segment tree or Fenwick tree.
5. **Social Graph Analyzer:** find components, shortest paths, and influential nodes.

## Study loop

```text
Understand → Draw → Implement → Test → Analyze → Optimize
```

For each project, write tests for empty input, one-item input, duplicates, large input, and invalid input.
