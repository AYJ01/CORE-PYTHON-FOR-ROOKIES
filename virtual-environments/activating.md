# Activating a Virtual Environment

## Windows

```powershell
.venv\Scripts\Activate.ps1
```

Command Prompt:

```bat
.venv\Scripts\activate.bat
```

## Linux and macOS

```bash
source .venv/bin/activate
```

The terminal prompt may show the environment name. Confirm the active interpreter:

```bash
which python
python -m pip --version
```
