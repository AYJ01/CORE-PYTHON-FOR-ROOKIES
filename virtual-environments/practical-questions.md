# Virtual Environments Practical Questions

1. Create a virtual environment named `.venv`.
2. Activate it on Windows.
3. Activate it on Linux or macOS.
4. Find the active Python interpreter.
5. Confirm the active `pip` is associated with that interpreter.
6. Install `requests` inside the environment.
7. List installed packages.
8. Upgrade an installed package.
9. Generate `requirements.txt`.
10. Create a second environment.
11. Install a package in only one environment.
12. Compare the package lists.
13. Deactivate the environment.
14. Try running a package after deactivation.
15. Re-activate the environment.
16. Add `.venv/` to `.gitignore`.
17. Recreate the environment from `requirements.txt`.
18. Explain why global package installation can cause conflicts.
19. Document setup instructions for a project.
20. Remove an environment directory.

## Mini-project

Create a project directory containing a virtual environment and a `requirements.txt` file. Document activation commands for Windows and Linux/macOS, then verify that the project imports its dependencies only from the environment.
