# File Handling Practical Questions

1. Open a text file for reading.
2. Read a file completely.
3. Read a file line by line.
4. Write text to a new file.
5. Append text to an existing file.
6. Use exclusive creation mode.
7. Copy a binary file.
8. Create a `Path` object.
9. Check whether a path exists.
10. Create a directory.
11. List all files in a directory.
12. Find all `.txt` files using `glob()`.
13. Read a CSV file with `csv.reader`.
14. Read a CSV file with `csv.DictReader`.
15. Write a CSV file with `csv.writer`.
16. Write JSON data with `json.dump`.
17. Read JSON data with `json.load`.
18. Handle a missing file with `try` and `except`.
19. Store a list of student dictionaries in JSON.
20. Build a simple logbook that appends timestamped entries.

## Mini-project

Create a contact manager that stores contacts in CSV or JSON. Support adding, listing, searching, updating, and deleting records. Validate input and handle missing or invalid files safely.
