2. Combine pytest parameters in a tuple.

4. Test an async function that waits for a delay.
5. Generate a coverage report.
6. Enable branch coverage.
7. Set a coverage threshold.
8. Replace a service with a stub.
9. Implement a stateful fake repository.
10. Verify a mock interaction.
11. Test file and database integration.
12. Use `tmp_path` for integration setup.
13. Install Hypothesis.
14. Define a property for sorting.
15. Define a property for serialization and deserialization.
16. Find a minimal failing property example.
17. Separate unit and integration test directories.
18. Skip an unavailable external integration cleanly.
19. Configure pytest in `pyproject.toml`.
20. Avoid testing implementation details when behavior matters.
