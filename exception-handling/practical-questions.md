# Exception Handling Practical Questions

1. Catch `ValueError` while converting input.
2. Catch `ZeroDivisionError`.
3. Handle missing dictionary keys.
4. Handle an out-of-range list index.
5. Catch two exception types separately.
6. Use `else` after a successful `try`.
7. Use `finally` for cleanup.
8. Open a file safely with a context manager.
9. Catch `FileNotFoundError`.
10. Catch `PermissionError`.
11. Print the exception type and message.
12. Raise `TypeError` for invalid argument types.
13. Raise `ValueError` for invalid argument values.
14. Create a custom exception.
15. Re-raise an exception after logging.
16. Chain a domain exception from a lower-level exception.
17. Design a retry mechanism.
18. Avoid catching `BaseException` for ordinary application errors.
19. Validate a user menu selection.
20. Build a safe calculator that catches invalid input and invalid operations.

## Mini-project

Build a bank account application with custom exceptions for insufficient funds, invalid accounts, and invalid withdrawals. It should use separate exception handlers, exception chaining where useful, and context managers for persistent account data.
