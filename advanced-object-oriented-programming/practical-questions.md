# Advanced OOP Practical Questions

1. Implement a `Car` class using an `Engine` through composition.
2. Implement an aggregate `Team` class.
3. Create an abstract `Shape` class.
4. Implement `Rectangle` and `Circle` subclasses.
5. Prevent abstract classes from being instantiated directly.
6. Convert a record class into a data class.
7. Give a data class default values.
8. Create a frozen data class.
9. Write a class-based context manager.
10. Use `contextmanager` to create a generator context manager.
11. Ensure cleanup code runs after an exception.
12. Create a descriptor for positive values.
13. Add `__get__` and `__set__` descriptor methods.
14. Create a custom metaclass.
15. Require specific methods during class creation.
16. Explain when composition is preferable to inheritance.
17. Explain how data classes reduce boilerplate.
18. Explain the difference between abstraction and implementation.
19. Explain the purpose of `__enter__` and `__exit__`.
20. Explain why metaclasses require caution.

## Mini-project

Build a plugin system that uses an abstract base class, validates plugin implementations through a metaclass or registration mechanism, and safely opens and closes plugin resources with context managers.
