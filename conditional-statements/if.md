# If Statements

The `if` statement executes an indented block only when its condition is true.

## Basic syntax

```python
number = 10

if number > 0:
    print("Positive")
```

## Boolean conditions

```python
is_member = True

if is_member:
    print("Welcome back")
```

## Comparisons

```python
temperature = 18

if temperature < 20:
    print("It is cool")
```

## Multiple statements

```python
score = 85

if score >= 50:
    print("Passed")
    print("Keep learning")
```

Only the indented statements belong to the `if` block.

## Practical questions

1. Print `"Even"` if a number is divisible by `2`.
2. Print `"Adult"` if age is at least `18`.
3. Print `"Free shipping"` if the purchase amount is at least `500`.
4. Print `"In stock"` if the quantity is greater than `0`.
5. Print a message if a password is not empty.
