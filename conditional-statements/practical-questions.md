# Conditional Statements Practical Questions

## Basic if statements

1. Print `"Positive"` if a number is greater than `0`.
2. Print `"Online"` if a status is `True`.
3. Print `"Contains Python"` if that text appears in a string.
4. Print `"Has items"` if a list is not empty.
5. Print `"Adult"` if a person's age is at least `18`.

## If-else

6. Print `"Even"` or `"Odd"` for an integer.
7. Print `"Pass"` or `"Fail"` for a score of `50` or more.
8. Print `"Large"` or `"Small"` for a number over `100`.
9. Print `"In stock"` or `"Out of stock"` for a quantity.
10. Select `"Yes"` or `"No"` using a ternary expression.

## Elif

11. Assign grades A through F from scores.
12. Categorize a person's age as child, teenager, adult, or senior.
13. Select a cost based on ticket class.
14. Print a different message for low, medium, and high temperatures.
15. Display a month name from a month number.

## Logical conditions

16. Check whether an age is between `18` and `65` inclusive.
17. Require both a login and a valid account.
18. Allow access if the user is an admin or has a valid pass.
19. Reject a balance that is negative or greater than a credit limit.
20. Skip processing if a value is `None` or an empty string.

## Nested conditions

21. Check whether a number is positive and even.
22. Permit entry only for users who are adults and have tickets.
23. Find whether a character is uppercase, lowercase, digit, or other.
24. Classify a score as passing or failing, then give an award for a high pass.
25. Check login status first, then role permissions.

## Mini-project

Create a program that:

- reads a name, score, and membership status;
- rejects an empty name;
- assigns a grade using `elif`;
- gives members a `10`-point bonus;
- prints `"Pass"` or `"Fail"`;
- prints `"Award"` only for a passing score of `90` or higher;
- uses a ternary expression for one of the final messages.
