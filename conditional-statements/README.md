## The main conditional forms

- `if` executes code when a condition is true.
- `if-else` chooses between two paths.
- `elif` checks additional conditions in sequence.
- Nested conditions place decisions inside other decisions.

## Quick example

```python
age = 20

if age >= 18:
    print("Adult")
else:
    print("Minor")
```
