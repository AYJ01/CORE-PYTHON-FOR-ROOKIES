# OOP Practical Questions

1. Create a `Student` class with name and score.
2. Initialize a class using `__init__()`.
3. Create two instances with different values.
4. Add an instance method.
5. Add a class attribute.
6. Create a class method.
7. Create a static method.
8. Protect an attribute using `_name`.
9. Protect an attribute using `__name`.
10. Create getter and setter properties.
11. Create a `Person` base class.
12. Create an `Employee` subclass.
13. Use `super()` to initialize inherited attributes.
14. Demonstrate multiple inheritance.
15. Override a base method.
16. Demonstrate polymorphism with a list of objects.
17. Implement a method required by an abstract base class.
18. Implement `__repr__()` for a class.
19. Implement `__len__()` for a container class.
20. Implement `__add__()` for a custom object.

## Mini-project

Create a library management system with `Book`, `Member`, and `Library` classes. Add methods to add books, register members, borrow books, and return books. Include validation and encapsulation.
